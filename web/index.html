بدون نصب روی هدف

فقط سرویس دسترسی از راه دور داخلی ویندوز (WinRM/OpenSSH) یا اندروید (ADB) را یک‌بار فعال کنید. هیچ فایلی روی دستگاه هدف کپی نمی‌شود.

هنوز دستگاهی اضافه نشده است

کافی است سرویس دسترسی از راه دور داخلی دستگاه هدف را یک‌بار فعال کنید؛ سپس آدرس و مشخصات ورود را اینجا وارد کنید. هیچ برنامه‌ای روی دستگاه هدف نصب یا کپی نمی‌شود.

🪟 ویندوز — WinRM سرویس داخلی ویندوز؛ مناسب اکثر نسخه‌ها
🔐 ویندوز/لینوکس — SSH OpenSSH داخلی؛ جایگزین امن
🤖 اندروید — ADB Wireless debugging؛ بدون اپلیکیشن

اندروید (ADB بی‌سیم)

روی گوشی: Developer options → Wireless debugging را فعال کنید. سپس با adb pair جفت کنید و با adb connect وصل شوید. هیچ اپلیکیشنی روی گوشی نصب نمی‌شود.
